# Ejercicio 8 - API de Juego de Tronos

Proyecto independiente creado con Vite.

## Cómo ejecutarlo

1. Abre una terminal dentro de esta carpeta.
2. Ejecuta `npm install` (o `npm ci`).
3. Ejecuta `npm run dev`.
4. Abre en el navegador la dirección local que indique Vite.

Para los ejercicios que muestran resultados en consola, abre las herramientas de desarrollador del navegador (F12) y selecciona «Consola».
